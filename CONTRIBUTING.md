# Contributing

This repository accepts public documentation fixes, installation feedback, and
sanitized compatibility reports for `@mastergo/dsh-canvas`.

Use GitHub Issues for reproducible bugs and feature requests. A useful report
includes the package version, DeepSeek Harness version, operating system,
architecture, expected result, and minimal reproduction steps.

Do not attach credentials, private document content, enterprise identifiers,
internal URLs, or complete runtime logs. Follow [SECURITY.md](./SECURITY.md) for
potential vulnerabilities.

The package's private development history and internal release infrastructure are
not mirrored in this public support repository. Source changes therefore follow
MasterGo's internal review and release process; a public issue can still be used
to track the externally visible behavior and published resolution.
